# v0.13.5 - Inicialização Automática no Boot

- 🚀 **Boot sem UAC:** O launcher agora se registra automaticamente na Tarefa Agendada do Windows para iniciar no logon com privilégios de Administrador, sem exibir o prompt do UAC.
- 🛠️ **Instalação como Admin:** O instalador agora força permissão de Administrador, garantindo que a interface nova substitua a antiga corretamente.
- 🖥️ **Interface Completa:** Seção de Tela (Resolução e Hz), Sistema separado (Volume e Brilho), navegação por sub-menus no controle e scroll automático.

# v0.13.5 - Modo Console Automático

- 🚀 **Boot Automático sem UAC:** O launcher agora cria uma Tarefa Agendada no Windows para iniciar automaticamente no logon com privilégios de Administrador, sem exibir o prompt do UAC.
- 🖥️ **Modo Console:** Após a instalação, o sistema reinicia automaticamente em 30 segundos e já abre o launcher em tela cheia (Kiosk Mode).
- 🛠️ **Instalação como Admin:** O instalador agora exige permissão de Administrador desde o início, garantindo que todos os arquivos (incluindo o FFmpeg) sejam instalados corretamente.
- 📸 **Correções:** A nova interface com seção de Tela (Resolução e Hz), Sistema separado (Volume e Brilho) e navegação por sub-menus com o controle estão totalmente implementadas.
