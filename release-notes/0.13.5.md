# Handheld Launcher 0.13.5 — versão consolidada

Esta versão reúne as melhorias planejadas nas versões 0.13.5, 0.13.6 e 0.13.7, com o fluxo de publicação corrigido.

## Novidades

- **Inicialização automática:** integração com Tarefa Agendada do Windows para iniciar o launcher no logon.
- **Modo Console/Kiosk:** opção de inicialização em tela cheia e ferramentas para configurar ou remover o modo console.
- **Quick Settings aprimorado:** interface reorganizada com submenus para controles, tela, sistema e captura.
- **Tela:** opções de resolução e frequência, conforme suporte do dispositivo.
- **Sistema:** controles de volume e brilho.
- **Captura:** atalhos e suporte à gravação de tela com FFmpeg incluído no pacote Windows.
- **Instalador:** manifesto do Windows solicita elevação de administrador quando necessário.

## Correções de publicação

- Removido o argumento `--requireAdmin`, que não é reconhecido pelo Velopack CLI 1.2.161. A exigência de administrador permanece definida no manifesto do aplicativo.
- Empacotamento Velopack passou a usar argumentos estruturados do PowerShell, evitando problemas de aspas e interpretação.
- Adicionadas verificações dos arquivos essenciais antes do empacotamento.

## Observação

O modo Console altera a inicialização do Windows e deve ser ativado conscientemente pelo usuário. Antes de usar em um dispositivo principal, confira as instruções de configuração e desinstalação incluídas no pacote.
