## 0.25.11 — capas de jogos Steam recém-lançados

- **Capas de jogos Steam:** o launcher buscava a arte só pelo ID da loja Steam. Jogos recém-lançados (ex.: **EA SPORTS FC™ 27**) às vezes já estão no SteamGridDB, mas sem o ID ligado, e ficavam sem capa. Agora, se o ID não traz nada, ele busca pelo nome — já sem ™, ® e pontuação. Vale para capa, fundo, logo, ícone e capa larga, e para a lista de escolha de arte.
