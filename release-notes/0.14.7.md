## 🎮 Aperfeiçoamento do Quick Settings Overlay

### ✨ Input block real — gamepad não vaza mais pro jogo
Quando você abre o overlay (L3+R3 ou Ctrl+Alt+O), o processo do jogo é **suspenso automaticamente** — o gamepad responde apenas no overlay, não no jogo atrás. Ao fechar o overlay, o jogo **retoma de onde parou**.

**Como funciona:**
- Watcher do launcher detecta o PID do jogo automaticamente
- Overlay suspende o processo via `NtSuspendProcess` (seguro, sem travar o launcher)
- Marker em disco garante recovery se o launcher crashar com o jogo suspenso
- Safety checks impedem suspender processos críticos (`explorer`, `svchost`, próprio launcher)

**Trade-off esperado:** o jogo **congela visualmente** (última frame na tela) enquanto o overlay está aberto. Isso é intencional — o input do gamepad não vaza e o jogo não "responde por baixo". Ao fechar o overlay, o jogo descongela instantaneamente.

### ⚡ Launcher volta em ~50ms ao fechar jogo
Antes: 8 segundos de espera com tela preta.

Agora: **~50 milissegundos**. O watcher verifica `Process.HasExited` a cada tick — quando o processo do jogo morre de verdade, o launcher volta na hora. O threshold de 8s continua existindo apenas para casos onde a janela desaparece mas o processo ainda está vivo (loading screens, tab-out).

### 🐛 Bugs corrigidos

**Watcher detecta Far Cry 6, Days Gone, eFootball™, e mais**
- Antes: `Contains` simples falhava com `®`, `™`, `©` em títulos (FarCry®6, eFootball™)
- Agora: normalização de título + match por executável como fallback
- `exeHint` detecta o `.exe` principal (maior arquivo, filtrado de installers/updaters)
- Funciona com Ubisoft Connect, Steam, Epic, e launchers intermediários

**Log spam reduzido em 95%**
- `exeHint detectado` loga 1x por mudança (era 1x por segundo)
- `Match por executável` removido do loop (o "Janela detectada" já avisa)

### 🔧 Melhorias internas
- Recovery automático de suspensão órfã (`InputBlockService.RecoverOrphanedSuspension`) — se o launcher crashar com o jogo suspenso, no próximo boot ele resumir o processo automaticamente
- Watchdog de popup aumentado de 60s para 90s (Far Cry 6 via Ubisoft Connect pode levar até 80s pra primeira janela)
- `GameHwnd` e `GamePid` registrados separadamente no overlay (foco funciona mesmo com overlay escondido)

## ⚠️ Comportamento conhecido

### Input block suspende o jogo
Enquanto o overlay está aberto:
- Jogo **congela visualmente** (frame parada)
- Áudio **para**
- Gamepad responde **apenas** no overlay (D-Pad, A, B, etc.)

Isso é **intencional** — o jogo não recebe input duplicado. Se o jogo travar após fechar o overlay (raro, em Ubisoft Connect), force restart via Gerenciador de Tarefas.

## 🔧 Notas técnicas

- `InputBlockService`: suspend/resume via `NtSuspendProcess`/`NtResumeProcess` com marker em disco
- `MainWindow.StartGameWatcher`: `EnumWindows` + normalização + executável hint + `HasExited` check
- `OverlayWindow.OnOpened`: chama `BlockGamepadForGame(_gamePid)` antes de mostrar
- `OverlayWindow.HideWithUnblock`: chama `UnblockGamepadForGame()` antes de `Hide()`
