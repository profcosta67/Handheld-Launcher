## 🐧 Handheld Launcher 0.24.3 — Linux nativo (beta)

Migração para Linux: o launcher passa a compilar e correr **nativamente** (sem Wine/Bottles), a partir da TFM `net8.0`.

> ⚠️ **Beta para teste.** Foco: validar o arranque, a biblioteca e o Quick Settings no Linux. O Windows continua igual à 0.24.2.

### O que já funciona no Linux
- **Arranque + UI** (Avalonia) e **biblioteca** (Steam/Epic/GOG/Heroic/Eden), capas e lançamento (`xdg-open`).
- **Quick Settings**: TDP via `ryzenadj`, brilho via `brightnessctl`, volume via `pactl`, resolução via `wlr-randr`/`xrandr`.
- **Gamepad** via `evdev` (`/dev/input/event*`) — D-pad, A/B, LB/RB, Start/Select e combo L3+R3.
- **Rede**: Wi-Fi `nmcli`, Bluetooth `bluetoothctl`, modo avião `rfkill`.
- **Lossless (frame-gen)** via **LSFG-VK**: o Quick Settings liga/desliga e escolhe 2x/3x/4x.
- **Syncthing** (binário do sistema).

### Instalação (Linux)
```bash
unzip HandheldLauncher-linux-x64.zip -d handheld-launcher
cd handheld-launcher
chmod +x install-linux.sh && ./install-linux.sh
handheld-launcher
```

### Requisitos / limitações (importante no Zorin)
- **Zorin (Ubuntu):** `nmcli`, `pactl` e `xrandr` já vêm. Para o resto: `sudo apt install brightnessctl ffmpeg` (e `ryzenadj` só se o APU for AMD).
- **Gamepad:** entre no grupo `input` e reinicie a sessão — `sudo usermod -aG input $USER`.
- **LSFG-VK:** precisa do `Lossless.dll` (proprietário) no `~/.config/lsfg-vk/conf.toml` ou configurado pelo Decky Framegen.
- **TDP** só aplica com `ryzenadj` instalado e com permissões (no Bazzite já vem).
