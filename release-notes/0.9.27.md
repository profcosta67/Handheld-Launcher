# Handheld Launcher 0.9.27

## Carrossel e biblioteca
- Oculta a barra de rolagem horizontal no layout Switch, mantendo a navegação horizontal e liberando a área inferior das capas.

## Programas
- Adiciona a opção de cadastrar programas na aba Programas.
- Permite selecionar manualmente um arquivo executável .exe.
- Permite localizar programas registrados no Windows que tenham caminho executável identificável.
- Preenche automaticamente nome e pasta de trabalho ao selecionar um programa encontrado.

## Correções
- Corrige a tipagem da lista de programas instalados para compatibilidade com os bindings compilados do Avalonia.
- Corrige o caminho de consulta ao registro de desinstalação do Windows.
