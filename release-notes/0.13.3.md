# v0.13.3 - Quick Settings Completo e Gravação

- 🎮 **Navegação Aprimorada:** Novo sistema de sub-menus no controle. Aperte "A" para entrar em uma opção (ex: Resolução) e use os direcionais para escolher o valor. "B" cancela.
- 🖥️ **Resolução e Taxa (Hz):** Agora você pode mudar a resolução e a taxa de atualização da tela direto pelo Quick Settings, sem precisar sair do jogo.
- 📷 **Tirar Print:** Atalho rápido que usa a API nativa do Windows para salvar em `Imagens/Screenshots`.
- 🎥 **Gravação de Tela:** Integração com o FFmpeg (em preparação). O botão já altera o status visual e inicia o processo de captura.
- ⚡ **TDP:** Adicionados os 4 modos (Eco, Normal, Desempenho, Boost) com trava de segurança térmica.
- 💾 **Persistência:** Todas as configurações (TDP, HUD, Cor, Volume, Brilho) são salvas automaticamente.
- 🛠️ **Fix de Scroll:** O ScrollViewer agora acompanha a navegação do controle automaticamente.
