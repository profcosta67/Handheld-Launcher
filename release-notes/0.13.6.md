# Handheld Launcher 0.13.6 — correção de inicialização

## Correções críticas
- Garante que o Velopack processe primeiro as operações de instalação e atualização antes da proteção de instância única.
- Impede a abertura de uma segunda janela: uma nova execução solicita que a instância existente volte ao primeiro plano e encerra.
- Aplica o bloqueio de watchdog/abertura automática antes de criar a janela principal.
- Remove a criação repetida da tarefa `HandheldLauncher_Startup` ao abrir a janela. A configuração da inicialização fica concentrada no script de instalação.
- Corrige a ordem dos métodos da interface COM `IAudioEndpointVolume`, necessária para chamar o método correto de volume master.

## Observações
- A tarefa agendada e o modo Console ainda precisam ser validados em um dispositivo Windows real (Legion Go/ROG Ally).
- Esta versão não declara como validados os controles TDP, brilho WMI, HUD ou gravação de tela.
- O script de instalação continua usando `-SkipReboot`: a reinicialização deve ser feita manualmente durante esta etapa de validação.
