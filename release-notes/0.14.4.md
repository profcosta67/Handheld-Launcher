# 🎮 Handheld Launcher v0.14.4 — O Destravamento do TDP!

Esta é uma das atualizações mais importantes do projeto. Finalmente desbloqueamos o controle total do TDP no hardware (focado no Legion Go 2 / Ryzen Z2) e reformulamos a interface para ficar digna de app nativo.

## 🚀 Novidades e Destaques

### ⚡ TDP Totalmente Destravado (Hardware Real)
- **Ryzen Z2 Mapeado:** O app agora reconhece o CPUID `0x75` e ajusta os endereços SMU corretos para a arquitetura Hawk Point/Zen 4 (`0x14`, `0x15`, `0x16`).
- **Ajuste Real no Chip:** O TDP não é mais apenas visual. O launcher envia os comandos via PawnIO e valida o retorno dos limites (Fast/Slow PPT) em tempo real.
- **Trava de Segurança:** O app aceita estritamente de 5W a 30W. É impossível aplicar valores que possam danificar o hardware.
- **Interface Consistente:** O Top Bar agora mostra o TDP Alvo em tempo real, com o Consumo Real (Watts) disponível no tooltip.

### 📊 HUD Reformulado e Inteligente
- **Nova Ordem de Exibição:** FPS → TEMP → BAT → HORA → GPU → CPU → RAM → TDP → FRAME → RES → REC (do mais importante para o menos útil).
- **HWiNFO Auto-Start:** O launcher agora tenta abrir o HWiNFO64 em segundo plano automaticamente para ler o consumo real do processador.
- **REC Inteligente:** O indicador de gravação não empurra mais o texto da resolução e agora fica piscando no final da linha.

### 🎥 Gravação Blindada (FFmpeg)
- Validação completa antes de iniciar: o arquivo `ffmpeg.exe` precisa existir, ter tamanho válido e não estar travado.
- O encerramento agora aguarda até 5 segundos e valida se o arquivo `.mp4` final tem mais de 0 bytes. Se falhar, avisa na UI em vez de gerar um arquivo corrompido.

### ⌨️ Atalhos de Teclado e Painel de Ajuda
- **Nova Aba "Teclas":** Agora você pode customizar os atalhos de teclado físico (ex: `Q`, `E`, `Ctrl+W`) direto na tela de Configurações.
- **Painel de Ajuda (F1):** Aperte `F1` (ou clique no ícone `i`) para abrir um painel moderno mostrando todos os comandos divididos entre **Controle** e **Teclado**.
- Acesso rápido ao painel de ajuda também pelo Menu Global (botão Start).

### 🌐 Cache de Metadados (RAWG)
- O app agora salva as descrições dos jogos em cache local por 30 dias.
- **Modo Offline:** Se a internet cair ou a API da RAWG falhar, o launcher usa o cache expirado para não deixar a tela em branco.

## 🛠️ Correções e Estabilidade
- **Boot Blindado:** Sistema de instância única configurado. O app não abre em loop no boot do Windows.
- **Gamepad Fix:** Corrigido o erro `OverflowException` que ocorria ao puxar o analógico no limite máximo.
- **Legion Space Independente:** O launcher agora gerencia os inputs diretamente via XInput, sem depender do software da Lenovo.
- Vários ajustes visuais na Top Bar e no alinhamento das fontes.
