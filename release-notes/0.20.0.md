## v0.20.0-beta.1

### ✨ Novo
- **Diário de Sessões**: o launcher agora grava tempo jogado em `%appdata%\HandheldLauncher\sessions.jsonl` (uma linha por sessão, formato JSONL)
- **Cérebro dos Aparelhos** já existente foi ajustado pra gravar TDP correto por sessão

### 🐛 Corrigido
- **Ghost click / delay no controle** (OverflowException no `GamepadPoller` quando o analógico atinge o limite mínimo) — finalmente resolvido, era `Math.Abs(short.MinValue)` estourando o `short`
- **`SessionTrackerService` agora também registra** quando o jogo fecha via Alt+F4 / saída externa (antes só gravava pelo botão do launcher)
- **`CloseRunningGame`** voltou a funcionar de fato (estava com `return` prematuro que impedia o close real)

### ⚠️ Conhecido
- **D-Pad do controle Xbox via Bluetooth não funciona no launcher** (limitação do Windows + XInput). Funciona no jogo, funciona no controle integrado do Legion, funciona via cabo USB-C. Fix definitivo virá com migração pra GameInput API (próximo ciclo).
