## v0.11.0 - O Handheld Launcher é um Console de Verdade 🎮

Esta é a maior atualização de experiência de uso até agora. Transformamos o launcher no "dono" do boot do Windows, adicionamos as tão esperadas capas animadas e refinamos o visual para um nível premium.

### 🚀 Modo Shell (Boot Direto)
- **Substituição do Explorer:** O instalador agora conta com a opção `-SetAsShell`. Isso faz o Windows bootar diretamente no seu launcher, sem abrir o desktop (explorer.exe) e, consequentemente, impedindo que o Legion Space ou o Xbox app apareçam na frente!
- **Botão de Emergência:** Adicionado o item "Sair para o Windows" no menu de Energia. Se você quiser voltar ao desktop normal a qualquer momento, basta clicar nele e o Windows volta ao normal.

### 🎞️ Capas Animadas (Animated Covers)
- **Suporte a GIFs e WebPs:** O launcher agora exibe as capas animadas do SteamGridDB nativamente na biblioteca principal e na roleta (tema Switch).
- **Filtro no Seletor:** Na tela de escolher capa, adicionamos o botão "Só animadas" para facilitar a sua busca.
- **Proporção Inteligente:** O launcher agora ignora imagens verticais na hora de buscar o Banner (Hero) principal, garantindo que apenas imagens horizontais sejam usadas na tela inicial.

### 🎨 Melhorias Visuais e Performance
- **Banner Hero Premium:** O banner principal agora tem um gradiente suave nas bordas, fundindo a imagem ao fundo e eliminando cortes secos.
- **Animações Fluidas:** O fundo desfocado do banner foi otimizado (Blur reduzido e opacidade controlada) para que as animações rodem de forma leve e fluida.
- **Seletor de Capas:** Correção no seletor para exibir as imagens no tamanho real, sem quadradinhos ou distorções.

### 🐧 Preparação Contínua para Linux
- O Core do launcher continua 100% compatível com Linux, com leitura de hardware nativa e execução de jogos via `xdg-open`.

*(Nota: Para aproveitar o modo Shell no Windows, execute o instalador via PowerShell usando a flag `-SetAsShell`.)*
