## Handheld Launcher 0.9.24

- **"Reiniciar o aparelho" e "Desligar o aparelho"**: encontrada uma causa
  provável, e ela explica certinho o sintoma de "não acontece nada, sem
  erro nenhum".

  O comando que o launcher usava pedia o desligamento **com educação**: o
  Windows pergunta a cada aplicativo aberto se pode encerrar, e **basta um
  recusar para cancelar tudo** — silenciosamente, com o comando até
  reportando sucesso. Num handheld isso é o caso comum, não a exceção:
  Legion Space, app do Xbox, Steam ou um jogo aberto, qualquer um deles
  basta para travar.

  Agora o desligamento é forçado. O custo é real e assumido: um jogo aberto
  perde o que não estiver salvo. Isso é aceitável porque o caminho exige
  três passos deliberados — Energia → Reiniciar/Desligar → confirmar "Sim"
  numa segunda tela. Um botão de desligar que não desliga é pior que um que
  desliga de verdade.

  Se ainda assim não funcionar, o `debug.log` (em
  `%AppData%\HandheldLauncher\`) agora registra o comando, o código de
  saída e a mensagem de erro — foi adicionado na v0.9.21.

- **Revisão do tipo de bug que apagou o nome editado** (v0.9.23): varri o
  resto do projeto procurando o mesmo padrão — código que recria um objeto
  campo a campo e perde o que não estiver na lista. **Não há mais nenhum
  caso.** Os outros pontos que gravam configurações já usam o jeito seguro
  (ler o arquivo, mudar só o campo, gravar de volta), e os scanners criam
  entradas novas a partir do disco, sem copiar nada.
