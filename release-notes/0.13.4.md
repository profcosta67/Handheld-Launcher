# v0.13.4 - Instalação Corrigida e Novo Layout

- 🛠️ **Correção de Instalação:** O instalador agora exige permissão de Administrador desde o início, garantindo que a interface nova substitua a antiga corretamente.
- 🖥️ **Seção de Tela:** Novo layout com botões separados para Resolução e Taxa (Hz).
- 🔊 **Sistema Separado:** Volume e Brilho agora têm seus próprios blocos.
- 🎮 **Navegação com Controle:** Sub-menus implementados (Aperte "A" para entrar na opção, direcionais para escolher, "A" para confirmar e "B" para cancelar).
- 📜 **Scroll Automático:** A tela acompanha o foco do controle automaticamente.
