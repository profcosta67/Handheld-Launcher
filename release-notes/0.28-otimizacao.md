## 0.28 Otimização e base (em desenvolvimento — branch feature/0.28-otimizacao)

Ainda não entrou em nenhuma beta.

Fatia 1 — erros que não derrubam o launcher:
- **Botões assíncronos protegidos:** os 28 manipuladores `async void` (Central de Controle: Wi-Fi, Bluetooth, modo avião; Configurações: pastas, contas, atualizações; captura de tela e Lossless Scaling no painel; Ajuda; Atualização do sistema e de drivers; Adicionar jogo) passam por uma rede de segurança. Um erro neles vira uma linha `[UI-ERRO]` no log, com o nome do botão e o começo da pilha, e o launcher segue aberto. Antes, o erro subia para a tela e fechava o launcher, inclusive com um jogo aberto.
- **Erros engolidos passam a deixar rastro:** 20 `catch` vazios em Configurações, tiles, tema, vigia (watchdog) e rádios registram uma linha `[IGNORADO]` (uma vez por ponto), sem mudar o comportamento.

Fatia 2 — medir antes de mexer:
- **Cronômetro de abertura:** o log ganha linhas `[ABERTURA]` com quanto tempo cada etapa levou (processo pronto, serviços criados, lista de jogos montada, janela criada, janela aberta, interface ociosa), contando desde que o Windows criou o processo. Só mede, não muda nada. Com esses números dá para saber onde estão os 3 s antes de otimizar.

Fatia 3 — OverlayWindow dividido (sem mudança de comportamento):
- O painel de Configurações rápidas (2.241 linhas num arquivo só) foi dividido em 6 arquivos por assunto: base e construtor, abertura/fechamento/posição, controle e submenus, TDP e tela, ventoinha/cor/HUD, captura/Lossless/utilitários. As linhas de código são as mesmas, só mudaram de arquivo; nenhuma função foi alterada ou removida.
