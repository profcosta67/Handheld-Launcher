# Handheld Launcher v0.20.1 — Diário de Sessões e Estabilidade

## ✨ Novo
- **Diário de Sessões:** O launcher agora grava a duração de cada jogo aberto em `%appdata%\HandheldLauncher\sessions.jsonl`. O fechamento via botão do launcher ou Alt+F4 é registrado corretamente, sem duplicar sessões.

## 🐛 Corrigido
- **Ghost Click / Delay no Controle:** Corrigido um `OverflowException` no `GamepadPoller` que causava perda de comandos e cliques fantasmas quando o analógico atingia o limite máximo.
- **Quick Settings no Centro:** O QS não pisca mais no meio da tela; ele abre direto na borda direita usando a posição inicial antes da renderização.
- **Idempotência no Fechamento:** O `CloseRunningGame` foi reescrito para evitar que o `EndSession` rode duas vezes e grave sessões com duração zerada.

## ⚠️ Conhecido
- **D-Pad do Xbox via Bluetooth:** O Windows não repassa os botões do D-Pad de controles Xbox conectados por Bluetooth para o XInput. Use o controle integrado ou cabo USB-C. A migração para a API GameInput está no roadmap.
