## 🐧 Handheld Launcher 0.24.3-beta.5 — instalação no Linux corrigida

Beta focada **só no Linux** (o Windows continua igual à 0.24.2 / beta.4). Corrige o problema relatado no **Zorin OS**: o instalador dizia "Pronto", mas o comando `handheld-launcher` não respondia e o launcher não aparecia em lugar nenhum.

### O que estava errado
- **`PATH` só no próximo login.** O atalho era criado em `~/.local/bin`, que não está no `PATH` da sessão atual — daí o `handheld-launcher: comando não encontrado`.
- **Nenhuma entrada no menu de aplicações.** O script não criava nenhum `.desktop`, então o launcher não aparecia no menu nem no botão direito.
- **Sem bit de execução.** O pacote era compactado com `Compress-Archive` num runner Windows, que **não guarda permissões Unix**: `HandheldLauncher` e `install-linux.sh` chegavam sem `+x`.
- **Zero verificação.** O script copiava os ficheiros e terminava — sem testar o resultado, sem log, sem desinstalador.
- **~56 MB de binários Windows** (`ffmpeg.exe`, HidHide, PawnIO) viajavam dentro do pacote Linux.
- **Auto-arranque sempre ligado**, mesmo em PC/desktop.

### O que muda
- **`install-linux.sh` reescrito:** entrada no menu de aplicações (com ícone), atalho em `~/.local/bin`, `PATH` corrigido no `~/.profile` (bloco marcado, sem duplicar), verificação de `ldd` com o comando `apt`/`dnf`/`rpm-ostree` exato para o que falta, aviso se você não está no grupo `input` (gamepad) e log em `~/.local/state/handheld-launcher/install.log`.
- **Recusa correr com `sudo`/root** — era assim que a instalação ia parar em `/root/.local` e "desaparecia".
- **Auto-arranque passou a ser opt-in:** `./install-linux.sh --autostart`.
- **`uninstall-linux.sh`** (novo), também acessível por `./install-linux.sh --uninstall`. Preserva `~/.config/HandheldLauncher`; `--purge` apaga também.
- **Pacote Linux agora é gerado num runner Linux** (`ubuntu-latest`), em `.tar.gz` (**recomendado** — preserva permissões) e `.zip` com `chmod 755` aplicado antes de compactar. O workflow extrai o pacote gerado e **instala-o num `HOME` temporário** antes de publicar: se o atalho, o menu ou o desinstalador falharem, o release falha em vez de chegar a você.
- **~56 MB mais leve:** as ferramentas Windows saíram do publish Linux (condição de TFM no `.csproj`).
- O mesmo teste de fumo passa a correr em **todo envio** (`ci.yml`), para o Linux não voltar a partir sem ninguém notar.

### Instalação (Linux)
```bash
tar -xzf HandheldLauncher-linux-x64.tar.gz
cd handheld-launcher
./install-linux.sh          # NUNCA com sudo
```

Depois: procure **"Handheld Launcher"** no menu de aplicações, ou abra um terminal novo e use `handheld-launcher`. Para usar já nesta sessão: `export PATH="$HOME/.local/bin:$PATH"`.

### Requisitos / limitações
- **Zorin/Ubuntu:** `sudo apt install brightnessctl ffmpeg` (e `ryzenadj` só se o APU for AMD). O instalador lista exatamente o que falta.
- **Gamepad:** entre no grupo `input` e reinicie a sessão — `sudo usermod -aG input $USER`.
- **LSFG-VK:** precisa do `Lossless.dll` (proprietário) configurado em `~/.config/lsfg-vk/conf.toml`.
- **TDP** só aplica com `ryzenadj` instalado e com permissões (no Bazzite já vem).

### Como reportar
Use **Central de Ajuda → Reportar erro** e anexe o `~/.local/state/handheld-launcher/install.log`. Mencione a distro (ex.: Zorin 17) e o que aparece ao rodar `./install-linux.sh` no terminal.
