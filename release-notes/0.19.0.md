## 🚀 Handheld Launcher v0.19.0-beta.1 — O Cérebro dos Aparelhos

Esta é a primeira versão beta da v0.19 (Multi-aparelho). O foco principal é a fundação de hardware e a estabilidade visual.

### 🧠 Novo: Cérebro dos Aparelhos (Device Detector)
*   O launcher agora detecta automaticamente o modelo do aparelho (Legion Go 2, Legion Go S, ROG Ally) via WMI/BIOS e carrega os limites corretos de TDP.
*   **Legion Go S desbloqueado:** O aparelho não é mais bloqueado. Ele exibirá um aviso amarelo de "Não Validado", mas os perfis padrão de TDP estarão disponíveis para teste.

### 🎨 Design System e Fonte Dinâmica
*   O Quick Settings agora herda a fonte global do launcher em tempo real. Trocar a fonte (ex: para Comic Sans) ou o tamanho do texto nas Configurações reflete instantaneamente na MainWindow **e** no QS.
*   Correção de layout: os tamanhos de texto do QS estão fixos para não estourar a largura (440px), mas a fonte se adapta dinamicamente.

### 🛠 Correções e Estabilidade
*   **Quick Settings:** Removida a recriação desnecessária da janela (Destroy/Recreate), eliminando flashes e perda de foco.
*   **TDP Assíncrono:** A aplicação de TDP agora roda em background, não congelando a interface.
*   **Gravação:** Alerta visual "🔴 REC" pulsante no topo do QS e botão vermelho com "⏹ Parar" quando a gravação está ativa.
*   **Guardião de Suspensão:** Novo diagnóstico via `powercfg /requests` gravado no `debug.log` para identificar bloqueios de sleep.
*   **Menu Start:** Adicionado `ScrollViewer` para evitar que a lista de opções estoure a tela em resoluções 720p.

### ⚠️ Notas importantes
*   A gravação via FFmpeg agora exige o `ffmpeg.exe` na pasta `Tools` do executável (ou na raiz do projeto durante o debug).
*   Testes realizados apenas no Legion Go 2. O suporte oficial ao ROG Ally e Legion Go S entra nas próximas betas da v0.19.
