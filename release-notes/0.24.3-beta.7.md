## 🐧 Handheld Launcher 0.24.3-beta.7 — instalador de duplo-clique no Linux

O Windows não muda. Esta beta é sobre a **instalação no Linux**: o beta.6 já abre a janela, mas instalar continuava a exigir terminal, o arranque no login estava desligado e não havia atalho no ambiente de trabalho.

### O que muda

- **Duplo-clique para instalar.** O pacote extraído tem agora, na raiz, **um único ficheiro: `INSTALAR`**. Duplo-clique nele e abre um menu no terminal:
  ```
  1) Instalar e abrir sozinho no login (handheld)   [Enter]
  2) Instalar sem abrir no login
  3) Desinstalar
  ```
  No GNOME/Zorin, na primeira vez: botão direito no `INSTALAR` → **Permitir execução**. Depois disso, dois cliques bastam.
- **Atalho no ambiente de trabalho** — o instalador cria `~/Desktop/handheld-launcher.desktop` (ou `~/Área de Trabalho`, via `xdg-user-dir`), já executável e marcado como confiável (`gio`). O desinstalador remove-o.
- **Arranque automático no login** passa a ser a **opção 1 do menu** (o modo handheld). Quem preferir o terminal continua com o padrão antigo: `install-linux.sh` só liga com `--autostart`.
- **Pacote organizado** — a raiz deixa de ter 200 ficheiros:
  ```
  handheld-launcher/
  ├── INSTALAR.desktop     ← o instalador
  ├── instalador/          ← instalar.sh, install-linux.sh, uninstall-linux.sh, LEIA-ME.txt
  └── arquivos/            ← binário e tudo o que ele precisa
  ```
  Assim ninguém precisa de procurar o instalador no meio do `*.dll`.
- **`instalador/instalar.sh`** não duplica lógica: mostra o menu e delega no `install-linux.sh` (log, `ldd`, `PATH`, ícone e menu de aplicações continuam todos lá). Também aceita `--sem-perguntas`, `--autostart`, `--no-autostart`, `--desinstalar` e `--purge`.
- **`--no-desktop-shortcut`** no `install-linux.sh` para quem não quer atalho no desktop (e remove um que exista).
- **O CI testa isto em todos os envios:** o `scripts/package-linux.sh` extrai o pacote, corre `instalador/instalar.sh` num `HOME` temporário e só publica se o autostart, o atalho do desktop, o menu, o ícone, o `--selftest` e a desinstalação funcionarem — incluindo o caso "instalar sem autostart" a **remover** o autostart anterior.

### Instalação (Linux)

```bash
tar -xzf HandheldLauncher-linux-x64.tar.gz
cd handheld-launcher
# duplo-clique em INSTALAR  (ou:)
./instalador/instalar.sh
```

Depois: procure **"Handheld Launcher"** no menu de aplicações, no ambiente de trabalho, ou use `handheld-launcher` num terminal novo. Para usar já nesta sessão: `export PATH="$HOME/.local/bin:$PATH"`.

Diagnóstico, se algo falhar:
```bash
handheld-launcher --selftest          # bibliotecas e serviços de arranque
cat ~/.local/state/handheld-launcher/install.log
```

### Requisitos / limitações
- **Use o `.tar.gz`**: é o único que preserva o bit de execução em qualquer extração. O `.zip` extraído no Windows e copiado para o Linux volta a ficar sem `+x`.
- **Zorin/Ubuntu:** `sudo apt install brightnessctl ffmpeg` (e `ryzenadj` só se o APU for AMD). O instalador lista exatamente o que falta.
- **Gamepad:** entre no grupo `input` e reinicie a sessão — `sudo usermod -aG input $USER`.
- A temperatura da CPU continua a mostrar `--°C` no Linux (o leitor de sensores é Windows-only).
- **LSFG-VK:** precisa do `Lossless.dll` configurado em `~/.config/lsfg-vk/conf.toml`.

### Como reportar
**Central de Ajuda → Reportar erro** com o `~/.local/state/handheld-launcher/install.log` e a saída de `handheld-launcher --selftest`. Indique a distro (ex.: Zorin 17).
