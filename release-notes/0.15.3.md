Esta atualização é um marco para o Handheld Launcher. Focamos em três pilares: estabilidade, velocidade de abertura e inteligência no download de capas.

## 🚀 Destaques da Atualização

### ⚡ 1. Performance e Boot (Patinho Turbo)
- **Abertura instantânea:** O launcher não trava mais na tela inicial. A validação de imagens (Self-Heal) e HWiNFO rodam em segundo plano.
- **Fim dos loops infinitos de download:** Se o SteamGridDB não tiver um logotipo, o launcher anota e não fica tentando eternamente.
- **Troca de temas mais fluida.**

### 🖼️ 2. Download de Capas e Emuladores
- **Busca com acentos:** "Pokémon" e "Pokemon" agora são tratados como o mesmo jogo.
- **Suporte a emuladores:** Sufixos como `-002` (gerados pelo Eden) são ignorados na busca.
- **Fallback de Capa Wide:** O layout Moderno usa o Banner como Capa Wide se a imagem específica não existir.

### 🎮 3. Navegação e Interface (UI/UX)
- **Scroll 100% Suave:** Removido o efeito "borracha" na fileira do layout Clássico.
- **Overlay sempre no topo:** Correção do bug onde o HUD sumia no jogo. Agora ele se mantém visível sem piscar.
- **Janela de Update visível:** Não fica mais escondida atrás do launcher.
- **Configurações Redondas:** Novo popup de Wi-Fi/Bluetooth com retorno automático e navegação por controle (Start = Salvar, X = Salvar e Fechar).

### 🛡️ 4. Correções Críticas (Bug Fixes)
- **Fim do Crash Nativo (0xC00000FD):** Corrigido o Stack Overflow ao carregar certas imagens animadas (bug do Lossless Scaling). Lib atualizada para 2.1.4.
- **Self-Heal Blindado:** A rotina de limpeza não apaga mais imagens WebP válidas.
- **Novidades Automáticas:** A tela puxa as notas direto da API do GitHub.
